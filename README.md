# Colheita Vitural para Android

[Baixar a versão 4.9.24](https://raw.githubusercontent.com/efgjfmanoh-del/Colheita-Vitural-Updates/main/v4.9.24/ColheitaVitural.apk)

Instale o primeiro APK no celular. Nas versões seguintes, o jogo oferece o download ao abrir e o Android pede confirmação para instalar. Requer Android 8 ou superior, processador ARM e OpenGL ES 3.
